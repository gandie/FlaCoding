# Stückliste FlaFla IT-Infrastruktur

Dinge, über die wir uns freuen würden:

- Mini-PCs: Raspberry-PIs oder vergleichbar - stromsparend für Dauerbetrieb einfacher Dienste ( vmlt. Webapps )
- Router: (Krypto-)Leistungsstarke Router für Freifunk mit höherer Bandbreite
- Kabel, Netzwerkkabel ( CAT5 aufwärts ), ggf. Netzwerkdosen
- Switches, günstig wäre PoE-Support ( Power over Ethernet )
- WLAN-Repeater, günstig PoE
- Büro-Laptops, Desktop-PCs
- Festplatten, NAS, Backupsysteme
- USB-Sticks ( 16GB+ ) für Bootsticks, Live-Systeme und simplen Dateitransfer
- Drucker?
- Mäuse und Tastaturen
- Sensoren ( GPIO: Temperatur, Bewegungsmelder, Schall, ... )
